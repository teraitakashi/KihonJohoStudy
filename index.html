🔢 整列

- アルゴリズム
バブルソート ★★★
Bubble Sort
隣り合う要素を比較・交換し、最大値を順に末尾へ移動させる。
→
選択ソート ★★★
Selection Sort
未整列部分から最小値を選んで先頭と交換していく。
→
挿入ソート ★★★
Insertion Sort
各要素を既にソート済みの部分列の適切な位置に挿入する。
→
クイックソート ★★
Quick Sort
ピボットを基準に分割を繰り返す、平均 O(n log n) の高速整列。
→
マージソート ★★
Merge Sort
分割統治法で配列を再帰的に分け、整列しながら統合する。
→
ヒープソート ★★
Heap Sort
ヒープ構造を利用して最大値を繰り返し取り出し整列する。
→
シェルソート ★
Shell Sort
ギャップを縮めながら挿入ソートを繰り返し高速化する比較ソート。

Union-Find ★
Union-Find

🌳 木・グラフ

- アルゴリズム
二分探索木 ★★
Binary Search Tree
左 ≤ 根 ≤ 右の性質を持つ木。挿入・検索・削除を可視化。
→
幅優先探索 ★★
BFS
キューを使い近い頂点から順に探索。最短経路発見に有効。
→
深さ優先探索 ★★
DFS
スタック（または再帰）で深く潜ってからバックトラックする。
→
ダイクストラ法 ★
Dijkstra's Algorithm
重み付きグラフで始点から各頂点への最短経路を求める。
→
前順走査（Preorder） ★★
Preorder Traversal
根 → 左 → 右 の順で木のノードを訪問する。
→
中順走査（Inorder） ★★
Inorder Traversal
左 → 根 → 右 の順で訪問。二分探索木では昇順出力になる。
→
後順走査（Postorder） ★★
Postorder Traversal
左 → 右 → 根 の順で訪問。木の削除や式の評価に利用される。
→
